# metasalmon has moved

This repository is retired and is no longer a supported distribution of
`metasalmon`.

Active development continues in the Salmon Data Mobilization organization:

- Source: <https://github.com/salmon-data-mobilization/metasalmon>
- Documentation: <https://salmon-data-mobilization.github.io/metasalmon/>
- Releases: <https://github.com/salmon-data-mobilization/metasalmon/releases>
- Issues: <https://github.com/salmon-data-mobilization/metasalmon/issues>

Install the current package from its canonical repository:

```r
# install.packages("remotes")
remotes::install_github("salmon-data-mobilization/metasalmon")
```

Do not install from this retired fork. Its former package contents remain
available in Git history, and the complete development history is preserved in
the canonical repository.
